# Changelog

All notable changes to the "agentgraph-vscode" extension will be documented in this file.

## [1.0.0] - 2026-10-04

### Added
- Initial release of AgentGraph Visual Studio Code extension.
- 5-Plane Tree Explorer for Agents, Workflows, Rules, Knowledge, and Code AST.
- Real-time DAG Topology health, node/edge counter, and cycle detection.
- Interactive Mermaid Webview graph visualizer with zoom/pan and plane filters.
- BM25 fast search across all graph planes.
- Topological dependency resolver with output logging.
- Quality Gates runner integrated directly into VS Code.
- Auto-sync on save for AGENTS.md, rules, and code.
